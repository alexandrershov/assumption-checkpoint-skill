# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

If you believe you found a security issue in this project, email the maintainer or use GitHub's private vulnerability reporting if it is enabled for this repository.

Include:

- a description of the issue;
- steps to reproduce or inspect it;
- affected files or versions;
- potential impact.

## Scope

This project is an agent skill and plugin package. It does not run a service, process user data, or include application runtime code.

Security-sensitive reports may still include malicious instructions, prompt-injection risks, unsafe installation guidance, supply-chain/package metadata issues, or repository configuration problems.
